# 🏦 Banking Management System

A desktop-based **Banking Management System** built using **Python, PyQt5, and SQLite** for managing customer records through a simple graphical interface.

## ✨ Features

- ➕ Add new customers
- 👥 View customer records
- ✏️ Update customer information
- 🗑️ Delete customer records
- 🔍 Duplicate customer detection
- 💾 Persistent data storage using SQLite
- 🖥️ Simple desktop GUI using PyQt5

## 🛠️ Tech Stack

`Python` • `PyQt5` • `SQLite`

## 📋 Customer Information

The system manages:

- Customer ID
- Name
- Address
- Account Type
- Loan Status
